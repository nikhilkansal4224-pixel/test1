## 🚀 Deploying to Vercel

This repository is pre-configured for zero-friction **Vercel** deployment with:
- **Clean URLs** enabled (`/menu`, `/about`, `/reservation`, `/contact`)
- **Optimized Caching Headers** for CSS & JS assets
- **Security Headers** (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`)
- **Branded 404 Fallback** (`404.html`)

### Method 1: Deploy with Vercel Web Dashboard (Recommended)

1. Push this repository to your GitHub account.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your **`test1`** (or named) repository.
4. Leave the Framework Preset as **Other** (Static Site).
5. Click **Deploy**.

---

### Method 2: Deploy with Vercel CLI

You can deploy directly from your local terminal:

```bash
# 1. Run deployment preview
npx vercel

# 2. Deploy directly to production
npx vercel --prod
```
